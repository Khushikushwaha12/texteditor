# Scratchpad — Browser-Based Rich Text Editor

Scratchpad is a fully functional, multi-document text editor built entirely with 
vanilla HTML, CSS, and JavaScript — no backend, no database, no installation. 
All documents are created, edited, and auto-saved directly in the browser using 
localStorage, making it a zero-install, privacy-first alternative to traditional 
word processors.

## Features
- 📝 Rich text formatting — bold, italic, underline, headings, lists, alignment, font style & size, text/background color
- 📂 Multi-document workspace with rename, delete, and auto-save
- 🎤 Voice typing (Speech-to-Text) and 🔊 Read Aloud (Text-to-Speech)
- ✅ Real-time spelling & grammar suggestions
- 📤 Export documents as .txt, .pdf, or .docx
- 🌙 Dark mode, 🔍 in-document search, 🖨️ print support, and a distraction-free focus mode
- 📱 Fully responsive design

## Tech Stack
HTML5, CSS3, JavaScript (Vanilla) · Web Speech API · LanguageTool API · html2pdf.js · html-docx-js
